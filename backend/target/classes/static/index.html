📢 Automated Emergency & Safety Alert Routing Protocol

When an emergency or safety complaint is submitted, immediate multi-channel alerts are routed to the designated response authorities:

🚨 Medical Emergencies

Chief Warden, Hostel Management, Doctor and Nurse

⚡ Electrical Emergencies

Electrician, Chief Warden and Hostel Management

🔥 Fire Emergencies

Hostel Warden, Hostel Management and Fire Emergency Team

🛡️ Security Emergencies

Hostel Warden, Hostel Management, Hostel Security and Bouncers

☕ Full-Stack Java Spring Boot + MySQL + Pure HTML/CSS/JS Architecture

This application connects a clean, responsive HTML/CSS/Vanilla JavaScript frontend to a Spring Boot REST API backed by Spring Data JPA and MySQL.

Frontend Flow: HTML Form (emergency.html) ➔ JavaScript (fetch) ➔ Spring Boot REST Controller ➔ Service ➔ JPA Repository ➔ MySQL (emergencies table)

Core REST Endpoints:
• POST /api/students/register (Register student)
• POST /api/students/login (Validate student credentials)
• POST /api/emergencies (Submit emergency with automated alert routing)
• GET /api/emergencies (List all emergencies for Warden)
• PUT /api/emergencies/{id}/status (Update status to In Progress / Resolved)
• POST /api/complaints (Submit safety complaint, status=Pending)
• GET /api/complaints (List complaints)
• PUT /api/complaints/{id}/status (Update complaint status)
• GET /api/contacts (Emergency contacts directory)
• POST /api/admin/login (Admin / Warden authentication)
